# TG OSINT Bot 🤖

A Telegram bot that looks up a Telegram ID and tries to resolve it to a mobile number using the `aerosend.bond` API.

## ⚠️ Disclaimer

This bot is for **educational purposes only**. Unauthorized lookup of personal information is illegal. Use only with explicit consent.

## Features

- `/start` command with inline keyboard
- Lookup Telegram ID → Mobile Number
- Clean inline button navigation
- Heroku & GitHub ready
